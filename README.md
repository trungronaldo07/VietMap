# Vietnam Light Map

Trang web mô phỏng bản đồ 34 tỉnh/thành Việt Nam dành cho thử nghiệm hiệu ứng quà tặng.

## Chạy thử
Mở `index.html` qua một web server hoặc GitHub Pages. Trang được tối ưu cho màn hình điện thoại.

## Chức năng
- Hiển thị ranh giới 34 tỉnh/thành.
- Nhấn quà mô phỏng để thắp sáng tỉnh tương ứng, phóng to khu vực và hiển thị địa danh.
- Nhật ký quà, tổng điểm và bảng xếp hạng.
- Có nhãn Hoàng Sa và Trường Sa.

## Lưu ý
- Nút quà hiện tại chỉ là **mô phỏng**, chưa kết nối TikTok LIVE.
- Dữ liệu ranh giới GIS được tải từ các nguồn dự phòng bên ngoài; cần kết nối Internet.
- Nguồn dữ liệu: Nguyen Duy Liem, [Free-GIS-Data](https://github.com/nguyenduy1133/Free-GIS-Data). Vui lòng giữ ghi công nguồn dữ liệu.
- Bản đồ dùng [Leaflet](https://leafletjs.com/).

## Bật GitHub Pages
Trong repository, mở **Settings → Pages**. Ở phần **Build and deployment**, chọn **Deploy from a branch**, branch **main**, folder **/(root)** rồi nhấn **Save**.
